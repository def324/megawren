# Security policy

## Reporting a vulnerability

Please report security problems privately, not in a public issue. Use GitHub's [private vulnerability reporting](https://github.com/def324/megawren/security/advisories/new), which only the maintainer can see.

Include what you found, how to reproduce it, and the Megawren version (`megawren --version`). You'll get a reply as soon as possible, and credit in the fix's release notes if you'd like.

## Supported versions

Fixes go into the latest release. Upgrade with the method you installed with, for example `brew upgrade megawren` or by running the install script again.

## Checking a download

Release files and the container image come with signed build attestations and an SBOM. The README explains how to [verify a download](README.md#verify-a-download).
